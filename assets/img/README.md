# assets/img

Drop the photographs here. Filenames must match exactly — each slot in the
markup points at one by name.

| File | Size | Slot |
|---|---|---|
| `hero-venue.webp` | 1600 × 2000 (4:5) | Home hero |
| `door-client.webp` | 1600 × 1000 (16:10) | "Planning an event" card |
| `door-planner.webp` | 1600 × 1000 (16:10) | "Event planners" card |
| `door-vendor.webp` | 1600 × 1000 (16:10) | "Vendors" card |
| `verified-vendor.webp` | 1200 × 1500 (4:5) | The "Verified / Before listed" card |

Nothing here is required. Each slot is a tinted tile with the photograph
layered over it as a CSS background image, so a file that is missing simply
leaves the tint showing — no broken-image icon, no layout shift. Add them one
at a time and the page is never half-finished.

Prompts, crops and the conversion commands are in `docs/image-prompts.md`.
